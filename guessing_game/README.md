# 🎯 The Guessing Game (CLI)

A simple Python **command-line guessing game** where the player tries to guess a randomly generated number within a chosen range.

---

## 🕹️ How the Game Works

1. The user enters a **maximum number**.
2. The program generates a **random number** between `0` and the given maximum.
3. The user keeps guessing until the correct number is found.
4. The game validates inputs to ensure only valid numbers are accepted.

---

## 🚀 Features

- Random number generation using Python
- Input validation for safe user interaction
- Infinite guessing loop until the correct answer
- Clean and beginner-friendly logic

---

## ▶️ How to Run

```bash
python guess_game.py
