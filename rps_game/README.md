# Rock Paper Scissors ✊🏻 🖐🏻 ✌🏻

A simple **beginner-level Rock Paper Scissors game** built in Python.

---

## 📌 About

* Command-line (CLI) game
* Player vs computer
* Computer choice is generated randomly
* Winner decided using basic game rules

---

## 🧠 Concepts Used

* Functions
* User input
* Lists & dictionaries
* Conditional statements
* `random` module

---

## ▶️ Run the Game

```bash
python rps.py
```
