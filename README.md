# Python Foundation 🐍

This repository contains my **beginner-to-intermediate Python projects** built to strengthen programming fundamentals and problem-solving skills.  

The goal of this repository is to:

- Practice core Python concepts  
- Build logical thinking through interactive scripts and games  
- Track learning progress from basics to structured, modular projects  

---

## 📂 Folder Overview

### 01_basics
**Purpose:** Introduces Python fundamentals through interactive CLI games.  
**What it teaches:** Variables, data types, loops, conditionals, user input, randomization, and basic game logic.  

**Projects included:**
- `guess_game.py` – Number Guessing Game (Random number logic, loops, conditionals)  
- `rps.py` – Rock Paper Scissors Game (Random module, decision-making, input handling)  

---

### 02_data_structure
**Purpose:** Focuses on Python data structures and their practical use in small projects.  
**What it teaches:** Lists, dictionaries, loops, conditional logic, input validation, and modular function design.  

**Projects included:**
- `pass_check.py` – Password Checker (Input validation, string handling, conditional checks)  
- `quiz_app.py` – Quiz Game (Lists/dictionaries, score tracking, user input handling)  

---

### 03_file_handling
**Purpose:** Introduces file-based persistence and task management through CLI applications.  
**What it teaches:** File I/O, string manipulation, task tracking, modular function design, and persistence across program runs.  

**Projects included:**
- `todo_file_manager/` – To-Do File Manager (Add, list, complete, delete tasks with file-based storage)  

---

### 04_intermediate
**Purpose:** Demonstrates structured programming and modular application development.  
**What it teaches:** Nested dictionaries, CRUD operations, data persistence, and modular CLI design for more complex systems.  

**Projects included:**
- `student_management/` – Student Management System (Add, view, update, delete students, file-based persistence)
