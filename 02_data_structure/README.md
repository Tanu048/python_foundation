# 📦 Data Structures Projects (CLI)

This folder contains two command-line based projects built using Python.  
Both projects focus on strengthening core **data structure concepts**, **conditional logic**, and **user input handling** using simple, real-world examples.

No external libraries or frameworks are used.

---

## 🧠 Overview

The projects in this folder were built to practice how data structures such as lists and dictionaries are used to solve practical problems.

They demonstrate how logic, validation, and flow control work together in interactive CLI programs.

Projects included:
- Password Checker
- Quiz Game

---

## 🚀 Projects Included

### 🔐 Password Checker (CLI)

A simple password validation program that checks user-entered passwords against predefined rules.
---

**Key Capabilities**
* Takes user input securely via CLI
* Validates password based on conditions (length, characters, etc.)
* Provides clear feedback for valid or invalid passwords
---
**Concepts Used**
* Strings
* Conditional statements
* Logical operators
* Input validation

---

### ❓ Quiz Game (CLI)
